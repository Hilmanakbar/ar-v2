🔧 Konfigurasi GitHub

Hubungkan admin panel ke repositori GitHub agar model tersimpan secara terpusat dan semua pengguna dapat melihat konten yang sama.

🔑 Kredensial GitHub

Buat token di: github.com → Settings → Developer settings → Personal access tokens → Fine-grained → Permissions: Contents (Read & Write)

📋 Konfigurasi Tersimpan

🔒
Keamanan Token Personal Access Token hanya tersimpan di browser ini (localStorage). Tidak dikirim ke server manapun selain GitHub API secara langsung. Jangan bagikan token kepada siapapun.

🚀 Integrasi Netlify

Hubungkan repo GitHub ke Netlify agar setiap push otomatis men-trigger redeploy. Semua pengguna akan melihat model terbaru dalam ~30 detik.

1️⃣
Buka netlify.com dan login atau daftar akun gratis.
2️⃣
Klik "Add new site" → "Import an existing project".
3️⃣
Pilih "Deploy with GitHub" dan pilih repositori AR Portal Anda.
4️⃣
Biarkan pengaturan default, klik "Deploy site". Netlify akan memberikan URL unik seperti https://your-site.netlify.app.
5️⃣
Setiap kali admin mengupload model (via GitHub API), Netlify auto-redeploy dalam ~30 detik. Bagikan URL Netlify kepada pengguna.

📖 Cara Membuat Personal Access Token

1
Login ke github.com dan klik foto profil → Settings
2
Scroll ke bawah, klik Developer settings (di sidebar kiri bawah)
3
Klik Personal access tokens → Fine-grained tokens → Generate new token
4
Isi nama token (misal: "AR Portal Admin"), pilih expiration, pilih Repository access → Only select repositories → pilih repo Anda
5
Di Permissions → Repository permissions → Contents, pilih Read and write
6
Klik Generate token, copy token dan paste di form di atas. Token hanya tampil sekali!
